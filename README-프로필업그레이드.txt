LUMINA PROFILE 업그레이드 사용 방법

1. 기존 LUMINA-WEBSITE 폴더를 먼저 복사하여 백업하세요.
2. 이 폴더의 모든 파일과 폴더를 기존 LUMINA-WEBSITE 폴더에 복사하세요.
3. 같은 이름의 파일이 나오면 덮어쓰기 하세요. (기존 개인 수정 내용은 백업을 확인하세요.)
4. index.html을 실행하고 PROFILE을 누르세요.
5. 각 멤버 카드를 클릭하면 독립적인 멤버 페이지로 이동합니다.
6. images 폴더에 아래 JPG 사진을 넣으면 카드와 상세 페이지에 동시에 표시됩니다.

seoha.jpg, ijun.jpg, hamin.jpg, yuchan.jpg, doyun.jpg, sion.jpg, taeo.jpg, eunyul.jpg, rowoon.jpg, ihyeon.jpg

주의: 확장자를 .jpg로 맞추세요. PNG 파일이면 HTML의 src를 .png로 바꿔야 합니다.
멤버의 미확정 생년월일·포지션은 임의로 작성하지 않았습니다. 해당 멤버의 member-이름.html 파일에서 추후 공개 문구를 수정할 수 있습니다.
